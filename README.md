## 🔽 কিভাবে অ্যাপটি ইনস্টল করবেন?

> ⚠️ **বি.দ্র:** এই অ্যাপটি এখনো Google Play Store-এ প্রকাশিত হয়নি। আপনি এটি APK ফাইল আকারে নিচের ধাপগুলো অনুসরণ করে ইনস্টল করতে পারবেন।

### ✅ ধাপে ধাপে ইনস্টল নির্দেশনা:

1. নিচের লিংকে ক্লিক করে APK ফাইলটি ডাউনলোড করুন:  
   👉 **[ডাউনলোড করুন Amader Kandughar.apk](#)**

2. ডাউনলোড শেষ হলে, আপনার ফোনের **Downloads** ফোল্ডারে গিয়ে ফাইলটি খুলুন।

3. APK ফাইলটিতে ট্যাপ করুন। যদি "Install blocked" বা "Unknown sources" সংক্রান্ত বার্তা আসে:
   - **Settings > Security** এ গিয়ে  
     **"Install from unknown sources"** অপশনটি চালু করুন।

4. এবার আবার APK ফাইলটিতে ট্যাপ করে **Install** বাটনে চাপ দিন।

5. ইনস্টলেশন সম্পন্ন হলে অ্যাপটি **Open** করে ব্যবহার শুরু করুন।
